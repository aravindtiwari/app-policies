# app-policies

Public pages for our Android apps, served by GitHub Pages at https://aravindtiwari.github.io/app-policies/.

Right now: each app's `feedback.html`, which Settings > Send feedback opens and which forwards to the shared feedback form. The sources live in each app's `app-policies/<app>/` folder; `feedback.html` is generated by `app-playbook/tools/make_feedback_pages.py`.
